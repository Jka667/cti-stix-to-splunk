# CTI STIX/TAXII to Splunk

Pulls STIX 2.1 indicators from TAXII 2.1 into a Splunk lookup, dropping expired IOCs and tagging ATT&CK techniques.

**Skills:** Threat intelligence, STIX / TAXII, Python, Splunk lookups, MITRE ATT&CK

**Value:** Threat intel reaches the SIEM automatically, with less noise from stale IOCs and more context for triage.
